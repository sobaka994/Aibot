# Инструкция по запуску и использованию AI SMM Агента

## 1. Установка и первый запуск
**Внимание:** Не открывайте файл `index.html` напрямую двойным кликом! Приложение должно запускаться через специальную среду (Electron), иначе кнопки не будут работать.

### Вариант А: Запуск из исходного кода (для разработчиков)
1. Убедитесь, что у вас установлен **Node.js** (скачайте с nodejs.org).
2. Откройте командную строку (Терминал или Командная строка Windows).
3. Перейдите в папку с программой: `cd путь/к/папке/ai-smm-agent`
4. Выполните команду для установки зависимостей:
   ```bash
   npm install
   ```
5. Запустите приложение:
   ```bash
   npm start
   ```

### Вариант Б: Сборка .exe файла (для обычных пользователей Windows)
Если вы хотите получить обычный `.exe` файл, который запускается двойным щелчком:
1. Выполните шаги 1-4 из Варианта А.
2. Запустите сборку:
   ```bash
   npm run build
   ```
3. После успешного завершения, в папке появится директория `dist`, в которой вы найдете готовый `.exe` файл установки.

## 2. Настройка приложения (Почему могут не работать кнопки?)

Если приложение запустилось, но при клике на кнопки ничего не происходит, убедитесь, что вы выполнили первоначальную настройку:

### Шаг 1: Настройка ключей API (Обязательно!)
1. Перейдите во вкладку **"Настройки ИИ"**.
2. Для каждого выбранного провайдера (ChatGPT, Claude и т.д.) введите ваш личный **API ключ**.
3. **Обязательно нажмите кнопку "Сохранить настройки ИИ"** внизу страницы.

### Шаг 2: Настройка соцсетей
1. Перейдите во вкладку **"Соцсети"**.
2. Для Telegram введите `Bot Token` и `Channel ID`.
3. Для VK введите `Access Token` и `Group ID`.
4. Нажмите **"Сохранить настройки соцсетей"**.

### Шаг 3: Настройка конвейера
1. Перейдите во вкладку **"Настройки конвейера"**.
2. Укажите поисковый запрос (например, "Искусственный интеллект").
3. Нажмите **"Сохранить"**.

---

## 3. Запуск конвейера
Только после того, как все настройки сохранены, переходите на вкладку **"Дашборд"**.
*   Кнопка **"Запустить сейчас"** запустит поиск новостей, генерацию текста, создание промпта для картинки, оценку качества и публикацию (в зависимости от настроек) один раз.
*   Кнопка **"Включить автозапуск"** будет делать это автоматически каждые N минут.

Все действия и ошибки (например, если API ключ неверный или закончился баланс) будут выводиться в черном окне **"Лог работы"**. Внимательно читайте эти логи, если что-то не работает!
