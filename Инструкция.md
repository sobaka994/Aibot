# Автоматическое выравнивание фото в Adobe Photoshop Lightroom Classic

Эта инструкция описывает принцип работы функции выравнивания в Lightroom Classic и то, как использовать прилагаемые пресеты для автоматизации этого процесса.

## Логика работы Lightroom Classic и ограничения инструмента "Crop" (Обрезка)

Lightroom Classic — это программа неразрушающего редактирования (non-destructive editing). Все ваши действия (изменение экспозиции, цвета, кадрирование) записываются в виде текстовых параметров (`.xmp`).

**Важное замечание про инструмент "Обрезка и выпрямление" (Crop & Straighten):**
В инструменте обрезки (клавиша `R`) есть кнопка **"Auto"** (Авто) рядом с ползунком **Angle** (Угол). При её нажатии Lightroom выравнивает горизонт. **Однако**, архитектура пресетов Lightroom *не позволяет* сохранить нажатие кнопки "Auto" для инструмента Crop. Пресет может сохранить только *конкретный числовой угол* (например, поворот ровно на 3 градуса для всех фото). Поэтому создать XMP-пресет, который использует именно "Crop Angle Auto" технически невозможно.

**Решение: Инструмент "Upright" (Трансформация)**
К счастью, в Lightroom есть второй, более мощный инструмент выравнивания, который находится в панели **Transform (Трансформация)**. Он называется **Upright**. В отличие от обрезки, Upright *можно* сохранить в пресет в режиме "Auto", и Lightroom будет заново вычислять правильный угол индивидуально для каждой следующей фотографии! Это дает точно такой же (а часто и лучший) результат автоматического выравнивания горизонта.

Функция **Upright** имеет несколько режимов:
- **Level (Уровень):** Корректирует *только* горизонтальные искажения (заваленный горизонт). Это прямой и лучший аналог автоматического выпрямления через "Crop".
- **Auto (Авто):** Автоматически корректирует и горизонт, и легкие вертикальные искажения, балансируя изображение так, чтобы оно выглядело естественно.
- **Vertical (Вертикально):** Корректирует только вертикальные перспективные искажения (например, "падающие" здания).
- **Full (Полностью):** Комбинация полного выравнивания по вертикали и горизонтали.

*Важно:* Для наилучшей работы алгоритмов выравнивания рекомендуется сначала включить **Коррекцию профиля объектива (Lens Corrections)**. Это устраняет оптические искажения (дисторсию) самого объектива, благодаря чему алгоритм Upright срабатывает точнее.

## Пресеты "Auto Align" и "Auto Straighten"

Я создал для вас два пресета:
1. `Level_Upright.xmp` (Auto Straighten) — использует режим **Upright - Level**. Он только выравнивает заваленный горизонт (аналог автоматического выпрямления обрезкой).
2. `Auto_Upright.xmp` (Auto Align) — использует режим **Upright - Auto**. Он выравнивает горизонт и дополнительно правит легкие искажения перспективы.

Оба пресета также автоматически включают:
1. **Коррекцию профиля объектива** (исправляет оптические искажения).
2. **Ограничение обрезки (Constrain Crop)** — эта функция автоматически обрезает фотографию после выравнивания так, чтобы по краям не оставалось пустых (белых) зон из-за поворота кадра.

### Как внедрить (установить) пресеты в Lightroom Classic

1. Откройте **Adobe Photoshop Lightroom Classic**.
2. Перейдите в модуль **Develop (Коррекции)** (клавиша `D`).
3. В левой панели найдите вкладку **Presets (Пресеты)**.
4. Нажмите на значок **+ (плюс)** в правом верхнем углу панели Presets.
5. Выберите **Import Presets... (Импорт пресетов...)**.
6. В открывшемся окне найдите файлы `Auto_Upright.xmp` и `Level_Upright.xmp`, выделите их и нажмите **Import (Импорт)**.
7. Пресеты появятся в панели Presets в группе **Auto Actions**.

### Как запустить автоматическое выравнивание

У вас есть несколько способов использовать эти пресеты.

#### Способ 1: Применение к одному или нескольким фото вручную
1. В модуле **Develop** выберите нужную фотографию.
2. В панели **Presets** откройте группу **Auto Actions**.
3. Кликните по пресету **Auto Straighten (Upright Level)** для выравнивания горизонта. Фотография будет мгновенно выровнена.
4. *Лайфхак для массовой обработки:* Если вы выделите несколько фотографий в ленте (Filmstrip) внизу, затем нажмете кнопку **Sync (Синхронизировать)** в правой нижней части экрана, вы сможете выбрать галочку `Upright Mode` (и `Lens Profile Corrections`) и применить выравнивание сразу ко всем выделенным фото. Lightroom будет рассчитывать выравнивание *индивидуально* для каждого фото!

#### Способ 2: Автоматическое выравнивание при импорте фото
Это самый удобный способ, если вы хотите, чтобы все новые фотографии сразу импортировались с ровным горизонтом.

1. Нажмите кнопку **Import (Импорт)** в левом нижнем углу модуля Library (или `File -> Import Photos and Video...`).
2. Выберите папку с фотографиями, которые хотите добавить.
3. Посмотрите на правую панель окна импорта. Найдите раздел **Apply During Import (Применить при импорте)**.
4. В выпадающем меню **Develop Settings (Настройки коррекций)** выберите `Auto Actions -> Auto Straighten (Upright Level)`.
5. Нажмите кнопку **Import**.

Теперь Lightroom будет автоматически анализировать и выравнивать горизонт каждой фотографии прямо в процессе её добавления в каталог!

### Решение возможных проблем
Иногда алгоритм может ошибаться (например, если в кадре нет четких линий горизонта, или есть линии, идущие под углом, которые программа принимает за горизонт).
Если пресет выровнял фото неправильно, вы всегда можете:
1. Зайти в панель **Transform** в модуле Develop и нажать **Off**.
2. Или нажать `Ctrl+Z` (Windows) / `Cmd+Z` (Mac), чтобы отменить действие пресета.
3. Выровнять фото вручную через классический инструмент **Crop** (клавиша `R`).
