# Инструкция по использованию системы "Smart Cull" для автоматического отбора фотографий

Система "Smart Cull" состоит из двух частей: Python-скрипта для анализа фотографий с помощью нейросетей и компьютерного зрения, и плагина для Adobe Lightroom Classic, который применяет результаты анализа к вашему каталогу.

## Принципы и логика работы
1. **Экспорт:** Вы экспортируете серию фотографий из Lightroom в небольшом разрешении (JPEG).
2. **Анализ:** Python-скрипт сканирует папку с этими JPEG-файлами.
   - **Резкость (Blur):** Скрипт использует оператор Лапласа (Variance of Laplacian) для оценки резкости каждого кадра. Смазанные кадры получают низкий балл.
   - **Лица и глаза:** С помощью нейросети Mediapipe скрипт находит лица. Если он обнаруживает, что глаза закрыты (на основе метрики Eye Aspect Ratio), фото сильно штрафуется.
   - **Группировка (Серии):** С помощью перцептивного хеширования (ImageHash) скрипт находит серии похожих кадров (дублей), снятых с одного ракурса.
   - **Отбор:** В каждой серии скрипт выбирает **одно лучшее фото** (с наибольшей резкостью, открытыми глазами и наличием лиц).
3. **Результат скрипта:** Создается файл `cull_results.csv`, где каждому файлу присваивается рейтинг (звезды) и цветовая метка (Green - оставить, Yellow - лучший дубль, но с дефектами, Red - удалить/брак).
4. **Импорт в Lightroom:** С помощью плагина вы загружаете этот CSV файл обратно в Lightroom. Плагин находит фото по именам и автоматически расставляет звезды и цветовые метки.

## Шаг 1: Установка зависимостей (Python)

Для работы анализатора на вашем компьютере должен быть установлен Python (версии 3.8 и выше).
1. Скачайте Python с официального сайта: python.org и установите его. **При установке в Windows обязательно поставьте галочку "Add Python to PATH"**.
2. Откройте командную строку (cmd) или терминал (PowerShell / Terminal).
3. Установите необходимые библиотеки, введя следующую команду:
   ```bash
   pip install opencv-python mediapipe imagehash Pillow
   ```

## Шаг 2: Установка плагина в Lightroom Classic

1. Переместите папку `SmartCull.lrplugin` в удобное место на вашем компьютере (например, в папку "Документы").
2. Откройте Adobe Lightroom Classic.
3. В верхнем меню выберите **File -> Plug-in Manager...** (Файл -> Менеджер плагинов...).
4. Нажмите кнопку **Add** (Добавить) в левом нижнем углу.
5. Выберите папку `SmartCull.lrplugin` и нажмите **Select Folder** (Выбрать папку).
6. Убедитесь, что плагин "Smart Cull" появился в списке и отмечен зеленым (Installed and running).
7. Нажмите **Done** (Готово).

## Шаг 3: Как пользоваться (Рабочий процесс)

### 1. Подготовка фото (Экспорт превью)
Чтобы скрипт работал быстро, не нужно анализировать тяжелые RAW файлы.
- Выделите в Lightroom фотографии, которые нужно отобрать (в модуле Library/Библиотека).
- Нажмите **Export** (Экспорт).
- В настройках экспорта выберите:
  - Папка: Создайте временную папку (например, `C:\Cull_Temp`).
  - File Naming: Оставьте оригинальные имена файлов (Original filename). **Это очень важно!**
  - File Settings: Формат JPEG, Quality 60-80.
  - Image Sizing: Resize to fit -> Long Edge -> 1024 pixels. (Этого достаточно для анализа резкости и лиц).
- Экспортируйте фото.

### 2. Запуск анализа (Python)
- Откройте командную строку или терминал.
- Запустите скрипт `smart_cull.py`, передав ему путь к папке с экспортированными фотографиями:
  ```bash
  python путь\к\файлу\smart_cull.py C:\Cull_Temp
  ```
  *(Пример: если скрипт лежит на рабочем столе: `python C:\Users\Имя\Desktop\smart_cull.py C:\Cull_Temp`)*
- Скрипт начнет работу. В терминале вы увидите процесс анализа каждого кадра и группировки.
- По завершении в текущей директории (откуда вы запускали команду) появится файл `cull_results.csv`.

### 3. Применение результатов в Lightroom
- Вернитесь в Lightroom.
- **ОБЯЗАТЕЛЬНО:** Выделите (Select All) те же самые фотографии в сетке (Grid view), которые вы экспортировали на первом шаге. Плагин работает только с выделенными фото!
- В верхнем меню выберите **File -> Plug-in Extras -> Import Smart Cull Results...** (Файл -> Дополнения плагинов -> Import Smart Cull Results...).
- Откроется окно выбора файла. Найдите и выберите сгенерированный файл `cull_results.csv`.
- Плагин сопоставит имена файлов и применит рейтинги и цветовые метки:
  - **Зеленая метка + 5 звезд:** Лучший кадр из серии, резкий, глаза открыты.
  - **Желтая метка (без звезд):** Лучший кадр из серии, но есть проблемы (например, закрыты глаза или недостаточная резкость).
  - **Красная метка + 1 звезда:** Брак, смаз или худший дубль в серии.
- Теперь вы можете отфильтровать фото в Lightroom по цвету или звездам и продолжить работу! Временную папку `C:\Cull_Temp` можно удалить.
